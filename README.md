# Developer Field Notes

A small personal reference site that collects Git commands, the daily workflow, and habits I want available during bootcamp. Built for the TTP Residency Git Solo assignment.

## Features
- Git vs. GitHub explainer
- The daily loop: edit → stage → commit → push
- A command reference table (10+ Git commands)
- A "things I should not commit" safety section
- Responsive dark theme

## One Thing I Learned About Git
<!-- TODO: replace with something real in your own words -->
A file existing in my editor does not mean it's saved in Git — it has to be **staged** (`git add`) and then **committed** before it's part of the history.
